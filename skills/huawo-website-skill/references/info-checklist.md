# 信息收集清单 + 启发式提问示例

> AI 收集用户信息时用。每个风格需要的信息略不同,用户没有的就跳过。

---

## 通用信息(3 个风格都要)

| 字段 | 说明 | 启发式问题 |
|---|---|---|
| 名字/ID | 真名或网名 | 「你想在网站上用什么名字?真名还是网名都行」 |
| 一句话定位 | 用一句话说清你是谁 | 见下方「一句话定位」启发 |
| 一句话介绍 | 50-100 字稍微展开的自我介绍 | 见下方「一句话介绍」启发 |
| 邮箱 | 联系邮箱 | 「留哪个邮箱让别人联系你?不想留也行」 |
| 社交账号 | 你的社交平台 | 「Twitter/GitHub/小红书/即刻/公众号,有哪些留哪些」 |

### 启发:一句话定位

用户说不清时,给 3 种常见模式让用户挑:

> 常见的定位有这几种,你看哪个接近:
> - **① 身份型**:一个做 XX 的大学生 / 独立开发者 / 插画师
> - **② 价值观型**:用代码 / 画笔 / 文字做真实但有质感的事
> - **③ 反差型**:XX 专业,但更想做 YY
>
> 或者告诉我你平时被别人怎么介绍,我帮你提炼。

### 启发:一句话介绍

用户说不清时,给 3 种写法让用户挑:

> 可以用三种方式写:
> - **① 故事型**:2018 年我从大厂辞职,想做点让自己愿意每天打开的东西
> - **② 现状型**:目前在杭州,一个人做产品
> - **③ 价值观型**:我相信少即是多
>
> 挑一种风格,我帮你写。

## 极简现代风(`assets/02-极简现代风.html`)额外信息

| 字段 | 说明 | 启发式问题 |
|---|---|---|
| 所在城市 | 「你在哪个城市?」 | 直接问 |
| 正在做的事 | 2-4 件当前在做的事(项目/工作/创作) | 「最近 1-2 年在做什么?工作/项目/创作,列 2-4 件」 |
| 作品/项目 | 3-6 个作品,每个配名称+年份+一句话描述 | 见下方「作品启发」 |
| 一些想法 | 2-4 条短想法/观点/格言(可选) | 「有没有什么你特别相信的话?或者最近想通的事?」 |

### 作品启发

> 作品可以是:做过的项目、写过的文章、运营的账号、参加过的比赛、完成过的作品。**任何你做过的、拿得出手的都算**。先列 3-5 个,不用讲究。

### 作品数量跟模板槽位对齐

不同风格模板的作品槽位不一样:

| 风格 | 模板槽位 | 用户作品数量建议 |
|---|---|---|
| 极简现代风 | 4 个 | 4 个最好,3 个可以(删 1 卡),2 个也能用(删 2 卡) |
| 水墨安静风 | 3 个 | 3 个最好,2 个可以 |
| 温暖手作风 | 6 个 | 6 个最好,4-5 个可以(注意 nth-child 配色) |

**少于槽位**:按 SKILL.md「模板作品数量规则」处理(方式 A 删末尾卡 or 方式 B 保留占位)。
**多于槽位**:模板装不下,告诉用户「这次先放前 N 个,多的以后再加」,或者帮他精简到模板能装下的数量。

## 温暖手作风(`assets/04-温暖手作风.html`)额外信息

| 字段 | 说明 | 启发式问题 |
|---|---|---|
| 作品(3-6 个,灵活) | 作品名 + 形式/平台 + 年份 + 一句话描述。**数量灵活,用户有多少填多少** | 「列你做过的东西,3-6 个都行,每个告诉我:叫什么、什么形式(文章/作品/项目/账号)、哪一年、一句话描述」 |
| 时间轴 | 3-4 个近期节点(里程碑/事件) | 「最近 1-2 年有什么重要的节点?搬家/换工作/开始新项目/获奖/旅行,列 3-4 个」 |
| 兴趣标签 | 3-4 个主题标签 | 「你平时主要关注什么?水彩/食物/旅行/阅读/手作,挑 3-4 个关键词」 |
| 邮箱 + 2 个社交 | 同上 | 同上 |

### 作品不够 6 个怎么办

温暖手作风模板有 6 个作品槽位,但用户不一定有 6 个作品。按 SKILL.md「模板作品数量规则」处理:

- **优先**:让用户重新理解「作品」(项目/文章/账号/比赛/任何完整做过的东西都算)
- **实在不够**:删卡(注意 `nth-child` 错位)或保留占位符
- **判断不了**:问用户「你想删格还是留占位?」

### 「材料/形式」字段对不同身份

模板默认字段是「材料/形式」,偏手作/插画师。对不同身份适配:

| 身份 | 「材料/形式」改成 |
|---|---|
| 手作人/插画师 | 材料(水彩/拼贴/陶艺) |
| 内容运营/写作者 | 平台 + 形式(公众号/博客 + 文章/连载) |
| 开发者/产品人 | 项目类型(Web App/小程序/工具) |
| 学生/咨询师 | 形式(咨询/课程/活动) |

## 收集完毕后:跟用户确认

不管什么风格,收集完都要跟用户对一遍:

> 我整理一下你的信息:
> - 名字:XXX
> - 定位:XXX
> - 作品:XXX / XXX / XXX
> - 邮箱:XXX
> - 社交:XXX
>
> 对吗?有没有要改的?

**用户确认后**再进 Step 3 改文件。不要没确认就改。

---

## 提问节奏建议

不要一次问太多。按这个节奏:

1. **第一轮**:名字 + 一句话定位 + 所在城市(3 个简单问题,建立基本画像)
2. **第二轮**:一句话介绍 + 作品列表(让用户多想想)
3. **第三轮**:邮箱 + 社交(收尾)
4. **确认**:整理信息让用户确认

每轮之间告诉用户「先回答这几个,后面还有」,让用户有预期。
