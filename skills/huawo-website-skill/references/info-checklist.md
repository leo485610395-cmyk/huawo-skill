# 信息收集清单 + 启发式提问示例

> AI 收集用户信息时用。每个风格需要的信息略不同,用户没有的就跳过。

---

## 通用信息(7 个风格都要)

| 字段 | 说明 | 启发式问题 |
|---|---|---|
| 名字/ID | 真名或网名 | 「你想在网站上用什么名字?真名还是网名都行」 |
| 一句话定位 | 用一句话说清你是谁 | 见下方「一句话定位」启发 |
| 一句话介绍 | 50-100 字稍微展开的自我介绍 | 见下方「一句话介绍」启发 |
| 邮箱 | 联系邮箱 | 「留哪个邮箱让别人联系你?不想留也行」 |
| 社交账号 | 你的社交平台 | 「Twitter/GitHub/小红书/即刻/公众号,有哪些留哪些」 |

### 启发:一句话定位

用户说不清时,给 3 种常见模式让用户挑:

> 常见的定位有这几种,你看哪个接近:
> - **① 身份型**:一个做 XX 的大学生 / 独立开发者 / 插画师
> - **② 价值观型**:用代码 / 画笔 / 文字做真实但有质感的事
> - **③ 反差型**:XX 专业,但更想做 YY
>
> 或者告诉我你平时被别人怎么介绍,我帮你提炼。

### 启发:一句话介绍

用户说不清时,给 3 种写法让用户挑:

> 可以用三种方式写:
> - **① 故事型**:2018 年我从大厂辞职,想做点让自己愿意每天打开的东西
> - **② 现状型**:目前在杭州,一个人做产品
> - **③ 价值观型**:我相信少即是多
>
> 挑一种风格,我帮你写。

## 极简现代风(`assets/02-极简现代风.html`)额外信息

| 字段 | 说明 | 启发式问题 |
|---|---|---|
| 所在城市 | 「你在哪个城市?」 | 直接问 |
| 正在做的事 | 2-4 件当前在做的事(项目/工作/创作) | 「最近 1-2 年在做什么?工作/项目/创作,列 2-4 件」 |
| 作品/项目 | 3-6 个作品,每个配名称+年份+一句话描述 | 见下方「作品启发」 |
| 一些想法 | 2-4 条短想法/观点/格言(可选) | 「有没有什么你特别相信的话?或者最近想通的事?」 |

### 作品启发

> 作品可以是:做过的项目、写过的文章、运营的账号、参加过的比赛、完成过的作品。**任何你做过的、拿得出手的都算**。先列 3-5 个,不用讲究。

### 作品数量跟模板槽位对齐

不同风格模板的作品槽位不一样:

| 风格 | 模板槽位 | 用户作品数量建议 |
|---|---|---|
| 极简现代风 | 4 个 | 4 个最好,3 个可以(删 1 卡),2 个也能用(删 2 卡) |
| 水墨安静风 | 3 个 | 3 个最好,2 个可以 |
| 温暖手作风 | 6 个 | 6 个最好,4-5 个可以(注意 nth-child 配色) |
| 暗色高级风 | 4 个 | 4 个最好,3 个可以(删 1 幅),2 个也能用(删 2 幅)。全宽单幅纵向堆叠,删任意幅不乱 |
| 瑞士国际风 | 4 个 | 4 个最好,少几个都行(2×2 作品格,删任意格,编号重排即可) |
| 杂志编辑风 | 4 个 | 4 个最好(1 头条+3 简讯),少 1 个删 1 条简讯,头条不能删 |
| 新粗野风 | 4 个 | 4 个最好,少几个都行(奇偶配色,删任意卡不乱) |

**少于槽位**:按 SKILL.md「模板作品数量规则」处理(方式 A 删末尾卡 or 方式 B 保留占位)。
**多于槽位**:模板装不下,告诉用户「这次先放前 N 个,多的以后再加」,或者帮他精简到模板能装下的数量。

## 温暖手作风(`assets/04-温暖手作风.html`)额外信息

| 字段 | 说明 | 启发式问题 |
|---|---|---|
| 作品(3-6 个,灵活) | 作品名 + 形式/平台 + 年份 + 一句话描述。**数量灵活,用户有多少填多少** | 「列你做过的东西,3-6 个都行,每个告诉我:叫什么、什么形式(文章/作品/项目/账号)、哪一年、一句话描述」 |
| 时间轴 | 3-4 个近期节点(里程碑/事件) | 「最近 1-2 年有什么重要的节点?搬家/换工作/开始新项目/获奖/旅行,列 3-4 个」 |
| 兴趣标签 | 3-4 个主题标签 | 「你平时主要关注什么?水彩/食物/旅行/阅读/手作,挑 3-4 个关键词」 |
| 邮箱 + 2 个社交 | 同上 | 同上 |

### 作品不够 6 个怎么办

温暖手作风模板有 6 个作品槽位,但用户不一定有 6 个作品。按 SKILL.md「模板作品数量规则」处理:

- **优先**:让用户重新理解「作品」(项目/文章/账号/比赛/任何完整做过的东西都算)
- **实在不够**:删卡(注意 `nth-child` 错位)或保留占位符
- **判断不了**:问用户「你想删格还是留占位?」

### 「材料/形式」字段对不同身份

模板默认字段是「材料/形式」,偏手作/插画师。对不同身份适配:

| 身份 | 「材料/形式」改成 |
|---|---|
| 手作人/插画师 | 材料(水彩/拼贴/陶艺) |
| 内容运营/写作者 | 平台 + 形式(公众号/博客 + 文章/连载) |
| 开发者/产品人 | 项目类型(Web App/小程序/工具) |
| 学生/咨询师 | 形式(咨询/课程/活动) |

## 暗色高级风(`assets/05-暗色高级风.html`)额外信息

> 排版是居中轴对称的画廊式:所有内容沿中轴线居中,作品是全宽 16:9 单幅大图纵向堆叠,像看展。

| 字段 | 说明 | 启发式问题 |
|---|---|---|
| 所在城市 | 页脚/介绍里出现 | 「你在哪个城市?」 |
| 正在做的事 | 3 件当前在做的事 | 「最近在忙什么?工作/项目/创作,列 3 件」 |
| 作品 | 4 个全宽单幅,每个配名称+年份/分类+一句话描述 | 「列 4 个你拿得出手的东西,每个:叫什么、哪一年、一句话说明」 |
| 作品配图 | 每幅作品一张 16:9 横版图 | 「作品有没有配图?没有就留占位符,后面自己换」 |
| 头像/半身照 | 4:5 竖版照片一张,居中窄幅展示 | 「有没有一张合适的照片?没有就留占位符,后面自己换」 |

## 瑞士国际风(`assets/06-瑞士国际风.html`)额外信息

> 排版是非对称网格拼贴:名字占左侧大半,hero 右侧是竖排信息列;近况是三列模块卡,作品是 2×2 作品格。

| 字段 | 说明 | 启发式问题 |
|---|---|---|
| 一句话定位 | hero 眉标处,mono 大写小字(如「独立开发者 / 工具爱好者」) | 同「一句话定位」启发,提醒:这里越短越有力 |
| 当前状态 | 一小句(如「正在做 XX / 开放合作」),显示在 hero 右侧竖信息列 | 「你现在什么状态?开放合作吗还是在闭关做东西?」 |
| 正在做的事 | 3 件,每件配名称+一句话+年份,三列模块卡 | 「最近在做的 3 件事,每件一句话」 |
| 作品 | 4 个,每个配分类标签+名称+一句话+年份,2×2 作品格 | 「列 4 个作品,每个给一个分类标签(如「小程序」「文章」)+ 一句话」 |
| 基本信息 | 坐标/方向/经验(年限或阶段),显示在关于区右侧下沉信息块 | 「你在哪、专注什么方向、做了多久/什么阶段?」 |
| 头像 | 3:4 竖版,直角无修饰 | 同上照片启发 |

## 杂志编辑风(`assets/07-杂志编辑风.html`)额外信息

> 排版是报纸密排式:关于区双栏正文+跨栏拉引语+右侧侧栏;近况是两列简讯;作品一主三辅(1 头条+3 简讯式小作品)。

| 字段 | 说明 | 启发式问题 |
|---|---|---|
| 刊号年月 | 页头 `VOL.01 — [年月]`,默认用当月 | 不用问,填当前年月;用户想自定义再改 |
| 创刊年份 | 期号行中间「创刊 [年份]」(开始做这件事/上网的年份) | 「你哪年开始做现在这件事的?记不清就填个大概」 |
| 所在城市 | 页头右侧出现 | 「你在哪个城市?」 |
| 开篇导语 | 一段 50-80 字的自我介绍,编辑口吻 | 同「一句话介绍」启发,提醒可以写得更像杂志开篇 |
| 长自述 | 「关于我」正文,两到四段,双栏排版 | 「写写你的经历:从什么时候开始、做过什么、为什么走到现在」 |
| 一句拉引语 | 自述正文中插一句金句,跨栏居中展示(全文只插一条) | 「你的自述里有没有一句最想让人记住的话?」 |
| 正在做的事 | 4 条简讯,每条一句话 | 「最近在忙什么?列 4 件,每件一句话,像报纸简讯」 |
| 作品 | 4 个一主三辅:头条作品配 2-3 句描述,其余 3 个各一句话 | 「列 4 个作品:哪个最能代表你(当头条,多说两句)?其余 3 个各一句话」 |
| 头像照片 | 3:4 竖版 + 一句图注,关于区右侧栏 | 「照片 + 图注一句话(比如『摄于工作室』),没有就留占位」 |

## 收集完毕后:跟用户确认

不管什么风格,收集完都要跟用户对一遍:

> 我整理一下你的信息:
> - 名字:XXX
> - 定位:XXX
> - 作品:XXX / XXX / XXX
> - 邮箱:XXX
> - 社交:XXX
>
> 对吗?有没有要改的?

**用户确认后**再进 Step 3 改文件。不要没确认就改。

---

## 提问节奏建议

不要一次问太多。按这个节奏:

1. **第一轮**:名字 + 一句话定位 + 所在城市(3 个简单问题,建立基本画像)
2. **第二轮**:一句话介绍 + 作品列表(让用户多想想)
3. **第三轮**:邮箱 + 社交(收尾)
4. **确认**:整理信息让用户确认

每轮之间告诉用户「先回答这几个,后面还有」,让用户有预期。
