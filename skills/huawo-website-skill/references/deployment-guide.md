# 部署上线指南

> 用户拿到 HTML 文件后,想让它在线上能访问时用。
> 这份指南既给 AI 参考,也可以直接转给用户看。

---

## 为什么本地文件不够

用户双击 HTML 打开,只有自己能看。要让别人访问,必须**部署上线**——把文件传到一个有公网 IP 的服务器。

听起来复杂,实际上有免费工具能 30 秒搞定。

---

## 推荐方案:Netlify(最简单)

### 适合谁

- 完全不懂技术的用户
- 想 30 秒搞定
- 不在乎有没有自定义域名(先用免费的)

### 步骤

1. **打开** https://app.netlify.com/drop
2. **把整个文件夹拖进去**(不是单个 HTML,是包含 HTML + 所有图片的文件夹)
3. **等 30 秒**,Netlify 自动部署
4. **拿到一个 URL**,形如 `random-name-xxx.netlify.app`,这个 URL 谁都能访问

### 优点

- 不需要注册(匿名拖拽)
- 不需要 Git 知识
- 30 秒搞定
- 免费额度对个人网站完全够用

### 缺点

- URL 是随机的(ugly)
- 想换名字要注册账号

---

## 进阶方案:Vercel(需要 GitHub)

### 适合谁

- 有 GitHub 账号
- 想要自动部署(改了代码自动同步)
- 想要更稳定的部署

### 步骤

1. **把 HTML 推到 GitHub 仓库**
2. **打开** https://vercel.com
3. **用 GitHub 登录**
4. **Import 你的仓库**
5. **Vercel 自动部署**,拿到 URL

### 优点

- 自动部署(改了代码自动同步)
- 全球 CDN,访问快
- 支持自定义域名

### 缺点

- 需要 GitHub 账号
- 比 Netlify 步骤多

---

## 自定义域名(可选)

### 适合谁

- 想要自己的域名(比如 `huawo.netlify.app` 想换成 `huawo.com`)
- 愿意花钱买域名

### 步骤

1. **买域名**:.com 约 60 元/年,.cn 约 30 元/年(阿里云/腾讯云/Namecheap 都行)
2. **在部署平台绑定域名**:Netlify/Vercel 都有「Add custom domain」按钮
3. **在域名商的 DNS 设置里**指向部署平台(平台会给你具体的 DNS 记录)
4. **等 24-48 小时** DNS 生效

### 推荐域名商

- **国内**:阿里云(万网)、腾讯云(需要备案才能绑定国内服务器,但绑定 Netlify/Vercel 不用)
- **国外**:Namecheap、Cloudflare Registrar(便宜,续费透明)

## 部署前的最后检查

部署上线前,再过一遍:

- [ ] HTML 在本地浏览器打开正常
- [ ] 所有图片都放在 HTML 同目录
- [ ] 图片路径是相对路径(`./my-photo.jpg`),不是绝对路径(`C:\Users\xxx\...`)
- [ ] 手机端看一下不崩

---

## 常见问题

**Q: 部署后打开是空白页?**
A: 多半是图片路径错了。检查 HTML 里 `src="..."` 是不是相对路径,图片是否真的在服务器上。

**Q: 部署后中文字体变了?**
A: 如果用了 Google Fonts,国内可能加载不到。解决方案:
- 用国内镜像(比如 `fonts.loli.net`)
- 把字体文件下载到本地
- 或换成系统字体(`-apple-system` / `PingFang SC`)

**Q: 部署后别人访问很慢?**
A: Netlify/Vercel 默认有全球 CDN,应该不慢。如果慢,检查:
- 是不是图片太大(用 tinypng.com 压一下)
- 是不是用了 Google Fonts(国内慢)

**Q: 想改内容怎么办?**
A: 改本地 HTML,重新部署(Netlify 重新拖一次,Vercel 推到 GitHub 自动同步)。
