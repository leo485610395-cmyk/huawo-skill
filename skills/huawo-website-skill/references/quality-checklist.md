# 质量检查表 · 交付前必过

> AI 交付网站之前,按这个清单逐项检查。**任何一项不通过都不能交付**。

---

## 一、内容检查

| # | 检查项 | 通过标准 |
|---|---|---|
| 1 | 所有占位符都处理了 | 用户填了的全部替换;没填的明确告诉用户保留 |
| 2 | 没有编造内容 | 用户没给的(比如作品名)不要替他写,保留占位符 |
| 3 | 名字一致 | 用户给的名字在导航、Hero、页脚、版权等所有位置都一致 |
| 4 | 邮箱有效 | 邮箱格式正确(xxx@xxx.com),不是 `[你的邮箱]` 字面量 |
| 5 | 社交链接完整 | 社交账号有正确的链接格式(即使 href="#" 也要文字对) |

## 二、HTML 检查

| # | 检查项 | 通过标准 |
|---|---|---|
| 6 | 没有破坏 CSS | `<style>` 标签里的内容跟模板原文一致(可以用 diff 工具对照) |
| 7 | 没有破坏结构 | 板块数量、顺序跟模板一致 |
| 8 | 没有残留半个方括号 | `[xxx` 或 `xxx]` 这种破损占位符不能有 |
| 9 | 编码是 UTF-8 | 文件头有 `<meta charset="UTF-8">` |
| 10 | 双击能打开 | 在浏览器里打开,不报错,不空白 |

## 三、视觉检查

| # | 检查项 | 通过标准 |
|---|---|---|
| 11 | 桌面端正常 | 1440px 宽度下,布局对齐,内容不溢出 |
| 12 | 手机端正常 | 375px 宽度下,布局自动重排,内容可读 |
| 13 | 字号合理 | 中文正文 ≥ 16px(否则糊),标题对比明显 |
| 14 | 颜色对比够 | 文字跟背景对比够,看得清 |

## 四、风格一致性

| # | 检查项 | 通过标准 |
|---|---|---|
| 15 | 没有混入其他风格元素 | 极简站没有水墨装饰;水墨站没有手绘元素 |
| 16 | 没有炫技动效 | 没加复杂动画、3D、WebGL |
| 17 | 视觉锚点保留 | 各风格的标志性元素都在(印章/侧栏/胶带等) |

---

## 检查方法

### 自动检查(快速)

用脚本检查最基础的项:

```bash
# 在 skill 根目录跑
python scripts/check-quality.py 我的网站-极简现代风.html
```

脚本会检查:占位符是否全部替换、CSS 是否被破坏、基本 HTML 结构。

### 视觉检查(必须做)

脚本检查通过后,**必须**用浏览器打开看一遍。脚本检查不了视觉问题。

---

## 检查失败怎么办

| 失败项 | 处理 |
|---|---|
| 占位符没替换全 | 找漏的地方,补上 |
| CSS 被破坏 | 回退到模板原版,重新替换 |
| 手机端崩了 | 用 `@media (max-width: 768px)` 加手机端适配 |
| 颜色对比不够 | 调暗背景或加亮文字 |
| 混入其他风格 | 删掉混入的元素 |

修复后重新检查,**全过**才能交付。
