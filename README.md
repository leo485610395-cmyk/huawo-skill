栋哥那把尺子：**做不出 skill = 没讲清楚。**

每个 skill 装的是化我真正想通、跑过验证、别人拿去能用的东西。

1. **进合集的 skill 必须经过 skill 候选池验证**（原创 + 能干活 + 跑过 n=1）
4. **skill 就是工具**。

## 安装（照 dbskill 那套）

仓库推上 GitHub 后，把这条命令发给任何能执行本机命令的 Agent（Claude Code / Codex / TRAE 等）：

```
npx -y skills add leo485610395-cmyk/huawo-skill -g --all
```

装完对 AI 说一句就能用，例如：

```
用 huawo-fear-check 看看这段话：【粘贴你卡住的那段话】
用 huawo-goal-check 看看：我该不该学X / 想学但执行不了 / 学了用不上
```

## huawo-fear-check 的理论背景

这个工具里的判断不是拍脑袋，每条都有出处：

- **阿德勒·目的论**：反复问「怎么办」是有目的的——让别人替你担风险。要攻略是幌子，要的是许可
- **阿德勒·课题分离**：别人怎么评价你，是别人的课题。祛魅不是鸡汤，是分工
- **卡伦·霍妮·对认可的病态需求**：问时机、问措辞、问详细度，是把「被批准」当成了生存必需
- **艾利斯·灾难化**：用没发生的事吓自己，是经典认知歪曲，不是性格缺陷
- **卡尼曼·确定性效应**：为消灭最后 5% 的不确定，付出无限等待成本——「等一个稳妥时机」就是这个结构
- **埃里克森·同一性理论**：18-25 岁怕别人怎么看，是这个年龄的本职任务，不是病。这个工具只接「卡住动不了」的，正常走任务的人不归它管

所有诊断案例来自真实咨询对话，已隐身份。

## huawo-goal-check 的理论背景

同上，每条判断都有出处（经五人评审团逐条攻击验证）：

- **洛克·目标设定理论**：目标不具体，行为就没有牵引——拖延、问该不该、学了没用，三张面孔一个病根
- **弗兰克尔·意义疗法**：意义在使用里显现，不在头脑预演里——「学完拿它干什么」就是意义的具体形态
- **瑞安·自我决定论**：「应该」背进来的目标答得最脆、崩得最快——目标不光要有没有，还要验成色
- **阿德勒·个体心理学**：有的目标不是拿来到达的，是拿来避难和挡「我没方向」这句话的
- **西蒙·有限理性**：门外是零信息决策，动手是最快的信息采集；不可逆的决定没有试错空间，谁也别替谁盖章

所有诊断案例来自真实咨询。
