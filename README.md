# huawo skill · 化我的开源 skill 合集

> 帮大学生把 AI 用到真实要做的事情上，完成可检查、可继续修改的初版，并留下下次能用的经验。


## 为什么开源

栋哥那把尺子：**做不出 skill = 没讲清楚。**

把做事过程中的问题、判断和方法整理成可试用的工具；每个 Skill 的适用范围、已做检查和待验证项分别说明。


## 合集原则

1. **按实际证据说明状态**：文件检查、模型合成试跑、真人使用分开记录；候选版公开供试用，不承诺已经稳定有效。
2. **skill 就是工具**：针对明确问题使用，保留本人判断与选择。

合集目前包含七个技能。把下面这段发给能读取和保存本地文件的 Agent（例如 WorkBuddy、Codex 或 Claude Code），由它按实际宿主能力处理：

## AI 兜底主入口

第一次使用可以直接说：

```text
请使用 huawo-ai-doudi，帮我完成【具体事情】。已有【材料或进度】，目前卡在【自己的原话】。接着当前进度带我做，缺信息时一次只问一个问题；需要其他 Skill 时先读取，找不到就说明。
```

主入口围绕“定交付、备材料、做判断、跑流程、留经验”推进，按需使用已经安装的工具；不是让每个人依次跑完所有 Skill。不会操作先补方法，用途不清才梳理目标，确有顾虑才讨论顾虑。个人网站是可选实践，不是必修。

主入口目前为公开试用版。用真实成果和反馈判断是否能用，不把格式检查或模型试跑等同于真实成员效果。

留经验时先在当前对话理顺实际做法、本人想法、取舍理由、更正、成果状态和同类复用线索。只要对话笔记就留在对话；明确要求保存到文件或知识库时才写入并回读。分享、保存和制作 Skill 分别按本人意愿处理。

## 把反复问题做成 Skill

有同类问题和可复用做法时，huawo-ai-doudi 可在经验总结末尾邀请一次：“这类问题以后还会遇到，要不要把能复用的做法做成一个Skill？”本人愿意或已经主动要求后，读取 huawo-skill-creator，在当前对话继续；拒绝或想结束时正常收尾。

创作器先沿用已有沟通和经验，判断反复解决什么问题、哪些判断能复用、哪些只是本次特例，以及输入变化、边界和验收是否清楚。缺什么才采访，一次一个问题；不固定先问 AI 做到哪一步，材料足够就生成完整候选。一次案例可以支持待试初版，不能证明方法广泛有效。

```text
用 huawo-skill-creator，沿用前面沟通与经验，判断要反复解决什么问题、哪些做法能复用，缺什么再采访，帮我做成可试用的 Skill。
```

保留必要的想法、关键原话、取舍理由和更正，分清本人判断与 AI 建议。私有经验交接留在生成 Skill 目录外，不能为了保留上下文默认把整段聊天打包公开；创建、安装和发布分别处理。

## huawo-fear-check 的理论背景

这个工具里的判断不是拍脑袋，每条都有出处：

- **阿德勒·目的论**：反复问「怎么办」是有目的的——让别人替你担风险。要攻略是幌子，要的是许可
- **阿德勒·课题分离**：别人怎么评价你，是别人的课题。祛魅不是鸡汤，是分工
- **卡伦·霍妮·对认可的病态需求**：问时机、问措辞、问详细度，是把「被批准」当成了生存必需
- **艾利斯·灾难化**：用没发生的事吓自己，是经典认知歪曲，不是性格缺陷
- **卡尼曼·确定性效应**：为消灭最后 5% 的不确定，付出无限等待成本——「等一个稳妥时机」就是这个结构
- **埃里克森·同一性理论**：18-25 岁怕别人怎么看，是这个年龄的本职任务，不是病。这个工具只接「卡住动不了」的，正常走任务的人不归它管

所有诊断案例来自真实咨询对话，已隐身份。

## huawo-goal-check 的理论背景

同上，每条判断都有出处（经五人评审团逐条攻击验证）：

- **洛克·目标设定理论**：目标不具体，行为就没有牵引——拖延、问该不该、学了没用，三张面孔一个病根
- **弗兰克尔·意义疗法**：意义在使用里显现，不在头脑预演里——「学完拿它干什么」就是意义的具体形态
- **瑞安·自我决定论**：「应该」背进来的目标答得最脆、崩得最快——目标不光要有没有，还要验成色
- **阿德勒·个体心理学**：有的目标不是拿来到达的，是拿来避难和挡「我没方向」这句话的
- **西蒙·有限理性**：门外是零信息决策，动手是最快的信息采集；不可逆的决定没有试错空间，谁也别替谁盖章

所有诊断案例来自真实咨询。
