# huawo skill · 化我的开源 skill 合集

> 对标 dbskill（github.com/dontbesilent2025/dbskill）。围绕化我个人的认知主线——让大学生脱离学生思维，看世界运转，找使命——沉淀可开源的 skill。
> skill 免费引流，社群承接变现。这是栋哥那套商业模式的化我版。

## 为什么开源

栋哥那把尺子：**做不出 skill = 没讲清楚。**

每个 skill 装的是化我真正想通、跑过验证、别人拿去能用的东西。装不进去，说明没讲清楚。

开源不是慈善，是系统设计：免费 skill 引流 → 想要更多的人进社群 → 社群变现。skill 本身 0 元，靠系统和别的环节养。

## 合集原则

1. **只开源原创/半原创的**。别人的付费资产（Leo 框架、学者理论）绝不进开源合集
2. **进合集的 skill 必须经过 skill 候选池验证**（原创 + 能干活 + 跑过 n=1）
3. **私人工作流不进合集**（含 API Key、私人路径的 skill 单独管理）
4. **skill 就是工具，不插广告**。引流入口只出现在 README 和发布渠道，不进 SKILL.md

## 安装（照 dbskill 那套）

仓库推上 GitHub 后，把这条命令发给任何能执行本机命令的 Agent（Claude Code / Codex / TRAE 等）：

```
npx -y skills add leo485610395-cmyk/huawo-skill -g --all
```

装完对 AI 说一句就能用，例如：

```
用 huawo-fear-check 看看这段话：【粘贴你卡住的那段话】
```

## huawo-fear-check 的理论背景

这个工具里的判断不是拍脑袋，每条都有出处：

- **阿德勒·目的论**：反复问「怎么办」是有目的的——让别人替你担风险。要攻略是幌子，要的是许可
- **阿德勒·课题分离**：别人怎么评价你，是别人的课题。祛魅不是鸡汤，是分工
- **卡伦·霍妮·对认可的病态需求**：问时机、问措辞、问详细度，是把「被批准」当成了生存必需
- **艾利斯·灾难化**：用没发生的事吓自己，是经典认知歪曲，不是性格缺陷
- **卡尼曼·确定性效应**：为消灭最后 5% 的不确定，付出无限等待成本——「等一个稳妥时机」就是这个结构
- **埃里克森·同一性理论**：18-25 岁怕别人怎么看，是这个年龄的本职任务，不是病。这个工具只接「卡住动不了」的，正常走任务的人不归它管

所有诊断案例来自真实咨询对话，已隐身份。
